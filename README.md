# App_Graphlens

Source repository for **GraphLens**, an independent, third-party Splunk
application providing an interactive, Neo4j-like relationship-graph
explorer natively within Splunk Cloud Platform and Splunk Enterprise.
GraphLens does not require Neo4j or any other external graph database.

The application itself lives in [`graphlens/`](graphlens/) - see
[`graphlens/README.md`](graphlens/README.md) for the full documentation
index (installation, configuration, user guide, admin guide, architecture,
security, testing, AppInspect results, and more).
